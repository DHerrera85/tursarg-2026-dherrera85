# TursArg 2026

Recuperación y modernización de **TursArg**, proyecto grupal desarrollado originalmente en 2021 durante una Diplomatura Full Stack.

## Origen del proyecto

La versión original fue desarrollada en el repositorio:

`FullStackCatamarca/proyecto_g2-proyecto_g2`

Ese repositorio se conserva como referencia histórica y no se modifica durante esta recuperación.

## Objetivo de esta etapa

En 2026 se inicia una nueva etapa orientada a:

- recuperar el concepto y las funcionalidades valiosas del proyecto original;
- corregir problemas técnicos y de seguridad;
- modernizar la arquitectura y las tecnologías;
- completar la integración entre frontend, backend y base de datos;
- mantener visible la evolución entre el proyecto formativo de 2021 y esta nueva versión.

## Estado actual

Fase inicial de recuperación y modernización.

La aplicación original incluía o contemplaba:

- frontend HTML, CSS y JavaScript con Bootstrap;
- migración parcial a Angular;
- backend ASP.NET MVC en C#;
- Entity Framework;
- SQL Server;
- usuarios, perfiles y login;
- atractivos turísticos;
- localidades y departamentos;
- excursiones y circuitos;
- foro y chat;
- integración meteorológica en etapa de prototipo.

## Criterio de recuperación

Este repositorio parte del proyecto original de 2021, preservando su contexto histórico y diferenciando claramente el trabajo grupal original de la etapa de recuperación y modernización iniciada en 2026.
